# Original DriveMate map format v1 engineering pilot
Original compiler built on existing DriveMate road importer. Fixed 0.05 degree cells; integer microdegree coordinates; directed edge records with source/destination identity, destination cell, way identity, mm distance and ms cost; node turn rules plus global conservative rules. Gzip compact JSON, individual length and SHA256 in pinned manifest. Raw OSM way tags and vertex geometry plus place names are available as sections. Not a nationwide format guarantee: XML limited to 30 MB, no relation geometry, tile-crossing geometry without an internal vertex may be absent, no polygon clipping, no hierarchy/shortcut routing, no postcode or full address coverage. Unknown restrictions conservatively handled by existing importer; not legal or safety assurance. No external navigation or renderer source code copied. ODbL 1.0 attribution and share-alike apply to map data. Artifact only; no release or main merge. Next: streaming PBF, independent routing/geometry sections, binary encoding, per-region catalogs and cross-tile/UK benchmark.
