# National acceptance
Run manually after nationwide candidate succeeds. The workflow fetches that candidate, verifies archive/tiles, enriches the directed cell index and benchmarks five real UK trips and an offline diversion under a 500 MB compressed cache budget. This is a Python mirror of directed graph search, not actual Android performance. The diversion only passes the threshold if measured from the original route vertices at least 48.3 km; its fixed candidate coordinate may fail that threshold and must not be reported as a successful 30-mile deviation in that case. Bounded A* may fail long-distance tests; evidence must remain visible rather than bypass restrictions. No live Github range publication, Android acceptance, traffic, voice, lane or road certification. Manual dispatch is necessary on the draft branch once the archive exists; no main merge or public release.
