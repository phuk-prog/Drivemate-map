# Reviewed preview publication
After the regional pack PR and publication PR are reviewed and merged, manually run the workflow on main with the successful candidate run ID, its exact commit SHA, and publish_preview=true. The workflow checks run identity, same repository, ancestry, all three archive hashes, manifest identity, every cell hash, exact graph/render geometry, and inventory before creating a new preview release. It refuses existing release tags. Pin the published catalog entries in the app only after verifying the release assets and their digests. This workflow is not a driving approval or signed APK release. No publication is performed by opening this pull request.
