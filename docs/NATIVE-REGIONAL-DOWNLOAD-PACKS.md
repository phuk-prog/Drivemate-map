# Native regional downloadable packs
Builds two bounded candidate regions from the exact pinned UK source. Each ZIP contains the verified geometry/routing manifest and its original checksum-pinned cell files. Catalog entries specify immutable release identity, archive length/hash, manifest hash, source and inset bounds. The workflow uploads candidates only; no GitHub release publication or nationwide coverage is claimed. A release reviewer must verify both artifacts, road acceptance and immutable assets before adding the catalog entries to the Android app. The initial supported pack remains Cheadle/Stockport. Boundary handover and cross-pack routing are not implemented. No server.

The next compiler pass adds original roadside node IDs and explicit enforcement relations to each relevant cell. These optional records do not change the routing-edge verification contract. A third overlapping corridor extract supplies a separately verified continuous graph for short journeys spanning the initial two areas. It does not splice independently clipped graphs or claim arbitrary cross-region routing. All three outputs remain unvalidated artifacts until review and immutable release publication. The compiler fails on existing bounded source/cell/archive budgets rather than silently dropping details.
