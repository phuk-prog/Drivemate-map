# Directed cell lower bounds
For each pair of adjacent cells, record the minimum travel cost of any directed crossing edge. A reverse shortest path over this coarse graph yields an admissible lower bound on the real remaining route cost: it ignores all within-cell costs and restrictions, so cannot overestimate a feasible route. The Android detailed search still enforces every turn and follows every actual edge. This is a hierarchy-assisted heuristic, not contraction hierarchies, exact shortcuts, or a production long-distance benchmark. The national job in progress uses the earlier catalog; enrich_dmtiles_catalog.py can generate the new bound metadata from its completed verified archive without recompiling it. Missing metadata disables the heuristic. No publish or main merge. ODbL map data.
