# Map V2 candidate
One pinned UK OSM PBF is compiled into a single SQLite graph and full E7 road geometry store. Every directed graph edge is checked against the original way and node pair and both source coordinates. Road and cartographic ways retain original tags and vertices; mapped point addresses/entrances/POIs are indexed by name/postcode. The R-tree exposes bounded exact geometry independent of the z14 basemap; the read-only /v2/roads candidate validates source identity, bounds and response limits. This is not a public service or live deployment. Graph rules are the existing conservative car importer. No third-party data is mixed, no missing tags inferred, no road validation claim. Pilot and UK compilation gates are automatic on the development branch; candidate archives are not promoted. National resource limits, physical-device routing, full-resolution national MVT, search ranking/FTS, multipolygon/terrain, external dataset licences, signed catalog promotion, incremental regional packages and mobile offline activation remain separate validation and integration work. UK PBF source remains the authoritative complete input.
