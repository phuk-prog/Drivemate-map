# Coordinated independent navigation refresh
This workflow builds Valhalla and the navigation attribute index from exactly one immutable, checksum-verified Geofabrik UK snapshot. It checks five native car route probes, verifies source identity and records graph/database hashes and sizes. It uploads candidate artifacts only; does not overwrite production data or create a public release. No proprietary comparison content enters the dataset.
The weekly Sunday 02:20 UTC schedule activates only after merge to main and explicit repository variable DRIVEMATE_PAIRED_REFRESH_ENABLED=true. Manual dispatch allows pinning a specific published source tag. The existing three daily source checks remain separate. Weekly builds are expensive, even when the source is unchanged; measure resource usage before enabling. A candidate is not a live service: install both verified products together, stop the old gateway before replacement, smoke-test, then enable the new endpoint. Retain the previous matching pair for rollback. Full UK workflow has not yet been run; storage/runner time must be validated.

The optional manual `tile_tag` input binds a dated UK display catalog to the same source and emits `compatibility.json` with the catalog, UK archive, graph, intelligence and probe SHA-256 digests. The workflow refuses mismatched source identities or mutable tile tags. Without that input it produces a graph/intelligence pair only, not a complete compatibility contract. Catalog validation is metadata-only; actual tile downloads and Android rendering still require verification. No production activation.
