# National routing cells
Builds from exact verified public UK routing release, no large phone installation. Each independently gzip-compressed cell has its offset, length and SHA256 in a single indexed archive. The cell adjacency metadata supports conservative coverage planning, NOT hierarchical shortest paths or shortcuts. Candidate artifact only, no publication. UK graph source excludes unsupported restrictions conservatively. Cells include roads/places, no full cartographic features or raw way intelligence. Long distance performance and max tile limits must be validated. GitHub single release asset limit requires splitting if archive exceeds 2 GB; no publication until that is resolved.
